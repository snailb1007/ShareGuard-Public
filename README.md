# ShareGuard Public

This is the public issue tracker and documentation repository for **ShareGuard**, a privacy-first Android app that strips metadata and tracking parameters from shared content.

## Purpose

The main ShareGuard codebase is a private repository. This public repository serves two main purposes:
1. **Issue Tracker:** A place for users to report bugs, suggest features, and ask questions. Please use the [Issues](https://github.com/snailb1007/ShareGuard-Public/issues) tab.
2. **Documentation & Policies:** Hosting public-facing documents such as our [Privacy Policy](docs/privacy-policy.md).

## Privacy Policy

ShareGuard collects **zero** personal data and processes everything locally on your device.

View the full Privacy Policy here: [Privacy Policy](https://github.com/snailb1007/ShareGuard-Public/blob/main/docs/privacy-policy.md)
